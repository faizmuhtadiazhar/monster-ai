# ELECTRIC — TEST

Masukkan gambar kelas **ELECTRIC** untuk bagian **TEST** ke folder ini.

Ketentuan:
- Resolusi gambar minimal 32 x 32 piksel.
- Format: JPG, JPEG, atau PNG.
- Gunakan variasi sudut, jarak, latar, dan pencahayaan.
- Jangan gunakan foto yang sama/nyaris sama pada training dan test.
- Catat sumber, izin/lisensi, mode pengambilan, dan subjenis gambar pada dataset_manifest.csv.

Catatan kelas ELECTRIC:
- subtype=battery_device untuk baterai/perangkat elektronik.
- subtype=lightning_spark untuk petir/percikan listrik pada gambar/layar.
- Usahakan kedua subjenis terwakili dan catat subjenisnya pada dataset_manifest.csv.
