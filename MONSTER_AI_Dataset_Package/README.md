# MONSTER.AI Dataset Package

Paket ini berisi struktur folder dan panduan awal dataset, bukan kumpulan gambar siap latih.

1. Ekstrak ZIP.
2. Salin folder `dataset` ke root repository MONSTER.AI.
3. Gabungkan dengan folder `dataset` yang sudah ada; izinkan file README di dalam folder dataset diperbarui.
4. Tambahkan gambar sesuai panduan `dataset/DATASET_PLAN.md`.
5. Catat sumber dan izin pada `dataset/dataset_manifest.csv`.

Target awal: 50 gambar training + 10 gambar test per kelas. Gambar minimal 32 x 32 piksel.
