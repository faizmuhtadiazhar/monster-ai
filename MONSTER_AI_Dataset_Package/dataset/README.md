# Dataset MONSTER.AI

Kelas: Fire, Water, Electric, Plant, Rock.

- `training/`: gambar untuk melatih CNN.
- `test/`: gambar untuk evaluasi akhir.
- Resolusi minimal: 32 x 32 piksel.
- Format yang disarankan: JPG/JPEG/PNG.
- Jangan gunakan gambar yang sama atau hampir sama pada dua split.
- Ambil variasi dari objek nyata dan gambar yang ditampilkan di layar, karena kedua mode akan dipakai saat demo webcam.
- Jangan sampai model hanya mengenali latar, bingkai layar, atau kondisi pencahayaan.
- Lakukan augmentasi hanya pada data training, setelah pemisahan data.
- File gambar belum disertakan di paket ini; paket ini adalah struktur dan panduan awal.
